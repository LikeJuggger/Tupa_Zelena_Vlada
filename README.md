# Tupa_Zelena_Vlada

FCPXML → AAF

Конвертер таймлайну Final Cut Pro (.fcpxml) у AAF для Nuendo, Pro Tools, Resolve, Logic, Premiere.
Працює локально, нічого не відправляє в мережу (крім перевірки оновлень за кнопкою).

## Встановлення

**Windows:** двічі клікни `INSTALL.bat`. Він доставить Python, FFmpeg і Git (якщо їх немає)
і створить ярлик «Tupa_Zelena_Vlada» на робочому столі. Далі — тільки ярлик.

**Mac:** двічі клікни `Tupa_Zelena_Vlada.app` (перший раз: правий клік → Відкрити).

## Оновлення

Кнопка «Оновити» вгорі програми — підтягує свіжу версію з GitHub і перезапускається.

## Що вміє

- Кліпи на своїх місцях до семпла; стерео — одним треком, dual mono — двома
- Доріжки: мінімум / навести порядок (Голос, Музика, Шуми) / як у FCP
- Фейди; гучність кліпів поки не переноситься (0 dB)
- Вимкнені кліпи: лишити (на треки OFF) або викинути; обрізка по хронометражу
- Якщо медіа є — вшивається в AAF (mp3 → WAV автоматично), лише потрібні шматки із запасом
- Якщо медіа немає — посилання на оригінальні файли, перелінкуєш у DAW
